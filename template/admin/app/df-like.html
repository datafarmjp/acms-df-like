いいね通知

通知

通知対象はいいね追加時のみです。フォームログや連番は増やさず、管理者宛メール設定だけを利用します。
通知フォーム

メール本文では entry_id, entry_title, entry_url, object_type, object_id, like_count, liked_at, blog_id, referer を使用できます。

{entry_title} にいいねされました。URL: {entry_url} / 現在のいいね数: {like_count} / 日時: {liked_at}

いいね履歴インポート

CSV列: entry_id は必須です。任意で visitor_key, action, created_at, blog_id, object_type, object_id, user_id, referer を指定できます。未指定時は action=like、created_at=インポート時刻、visitor_key=行単位の内部キーで補完します。Excel等で混ざる不可視空白は取り込み時に補正します。

同じCSVを再実行しても履歴ログは重複せず、現在のいいね状態に不足があれば補修します。

集計

管理画面で集計するブログ

管理画面の集計・履歴・CSV・削除対象の範囲を切り替えます。いいねの保存先は変わりません。

CSV移行後など、履歴はあるのにフロントの件数へ反映されない時に使います。履歴ログは増やしません。

人気ランキングの設置方法

通常テンプレート

いいね数順の記事リンク一覧だけを表示したい場合は、公開ページに次のモジュールを設置できます。

<!-- BEGIN_MODULE DFLikeRanking --><!-- DFLikeRanking:limit=5 --><!-- BEGIN ranking:loop --><p><!-- BEGIN_IF [{entry_image_path}/nem] --><img src="%{ROOT_DIR}{entry_image_path}[resizeImg(160)]" alt="{entry_image_alt}" loading="lazy"><!-- END_IF --><a href="{entry_url}">{entry_title}</a> {like_count}</p><!-- END ranking:loop --><!-- END_MODULE DFLikeRanking -->

Twig / V2_DFLikeRanking

Twigでは V2_DFLikeRanking からランキング配列を取得できます。

{% set ranking = module('V2_DFLikeRanking', null, { limit: 5 }) %} {% for item in ranking.items %} <p><span>{{ item.rank }}</span> <a href="{{ item.entry_url }}">{{ item.entry_title }}</a> <span>{{ item.like_count }}</span></p> {% if item.entry_image_thumbnail %} <img src="{{ item.entry_image_thumbnail }}" alt="{{ item.entry_image_alt }}" loading="lazy"> {% endif %} {% else %} <p>いいねされた記事はまだありません。</p> {% endfor %}

オプション指定方法

必要に応じて、ランキングの表示件数や集計期間を指定できます。通常テンプレートではモジュール内の <!-- DFLikeRanking:... --> コメントで指定し、Twig/V2では module() の第3引数に指定します。

limit
表示件数です。未指定時は 5、最大 50 です。
period
集計期間です。all、today、7d、30d を指定できます。
start
任意期間の開始日です。YYYY-MM-DD 形式で指定します。
end
任意期間の終了日です。YYYY-MM-DD 形式で指定します。
entry_image_path
記事の標準メイン画像のパスです。画像がない場合は空になります。

通常テンプレート

<!-- BEGIN_MODULE DFLikeRanking --><!-- DFLikeRanking:limit=5;period=7d --><!-- END_MODULE DFLikeRanking --> <!-- BEGIN_MODULE DFLikeRanking --><!-- DFLikeRanking:limit=5;start=2026-05-01;end=2026-05-31 --><!-- END_MODULE DFLikeRanking -->
