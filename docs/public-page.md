# DFいいね

DFいいねは、a-blog cms のエントリーに「いいね」ボタンを追加する拡張アプリです。読者が気軽に反応できる導線を用意し、管理画面ではいいね数や履歴を確認できます。

## 主な機能

- エントリー本文の上部または下部に、いいねボタンを自動表示できます。
- テンプレートにモジュールを設置して、任意の位置にいいねボタンを表示できます。
- ボタン文言、色、マーク、いいね後メッセージを管理画面から調整できます。
- エントリーごとのいいね数や履歴を管理画面で確認できます。
- いいね後に短いメッセージを表示し、読者へのお礼を伝えられます。

## こんな場面に向いています

ブログ、コラム、製品情報、サポート記事など、コメントまでは求めないけれど読者の反応を知りたいページに向いています。小さな反応を積み重ねて、どの記事が読者に届いているかを把握できます。

## 利用について

a-blog cms の拡張アプリとしてインストールし、管理画面から表示位置や見た目を設定します。記事ごとの個別メッセージも設定できます。
